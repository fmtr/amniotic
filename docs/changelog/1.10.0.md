- Fixed serious memory leaks in audio streaming that could cause memory usage to grow significantly over time. Streams now release their resources more reliably, making long-running and repeatedly restarted streams much more stable.
- Reduced the memory and processing overhead of preparing audio for playback, further improving stability during continuous use.
- Improved support for stereo and multichannel recordings, including more consistent volume handling when converting them for playback.
- Fixed an issue where enabling multiple recordings made the overall mix quieter. Recordings are now combined at their intended volume without allowing the output to become distorted when the mix gets too loud.
- Reduced the size of the pre-built Docker image by approximately 50%.
